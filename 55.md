🎯 Overview

The masterclass follows a progressive, practice-oriented approach to competitive programming.

What You Will Learn

- Algorithmic Thinking: Develop logical reasoning and systematic problem-solving abilities.
- Implementation Skills: Translate problem statements into efficient, error-free code.
- Mathematical Reasoning: Apply number theory, modular arithmetic, combinatorics and bitwise operations.
- Algorithm Design: Understand greedy strategies and constructive algorithms.
- Graph Problem Solving: Work with trees, graph traversal and connectivity.
- Dynamic Programming: Identify overlapping subproblems and optimise recursive solutions.
- Competitive Programming Techniques: Improve complexity analysis, implementation speed and debugging skills.

💻 Getting Started

Prerequisites

To practise the problems, you will need:

- A C++17-compatible compiler (GCC 9+ recommended).
- Python 3.8+ (optional).
- A code editor such as Visual Studio Code.
- Basic knowledge of programming, data structures and algorithms.

Clone the Repository

git clone https://github.com/USERNAME/Competitive-Programming-Masterclass.git

cd Competitive-Programming-Masterclass

Replace "USERNAME" with the GitHub account or organisation hosting the repository.

Compile and Run C++ Solutions

g++ -std=c++17 -O2 -Wall solution.cpp -o solution

./solution

For Windows:

g++ -std=c++17 -O2 -Wall solution.cpp -o solution.exe

solution.exe

Run Python Solutions

python3 solution.py

🧠 Problem-Solving Guidelines

A recommended workflow for every problem:

1. Understand: Read the problem statement carefully and identify the input, output and constraints.
2. Analyse: Identify the relevant algorithmic paradigm or mathematical observation.
3. Design: Develop a solution and consider edge cases.
4. Estimate: Analyse time and space complexity.
5. Implement: Write a clean and efficient implementation.
6. Test: Validate the solution against sample cases and additional test cases.
7. Optimise: Improve the solution if it exceeds time or memory constraints.
8. Review: Understand alternative approaches and document important observations.

Complexity Reference

Complexity| Typical Interpretation
O(1)| Constant time
O(log n)| Logarithmic
O(n)| Linear
O(n log n)| Linearithmic
O(n²)| Quadratic
O(2ⁿ)| Exponential
O(n!)| Factorial

🤝 Contribution Guidelines

Contributions are welcome! You can help improve this repository by adding solutions, identifying errors, improving explanations or suggesting new problems.

How to Contribute

1. Fork this repository.
2. Create a new feature branch.
3. Add your solution using the established naming convention.
4. Test your implementation.
5. Submit a pull request with a brief explanation.

Solution Submission Format

Each solution should ideally include:

- Problem number and name.
- Original problem URL.
- Programming language.
- Algorithmic approach.
- Time and space complexity.
- Clean, readable source code.

Example:

/*
 * Problem: Watermelon
 * Platform: Codeforces
 * Problem ID: 4A
 * Language: C++17
 * Approach: Mathematical Observation
 * Time Complexity: O(1)
 * Space Complexity: O(1)
 */

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    cout << (w > 2 && w % 2 == 0 ? "YES" : "NO") << '\n';

    return 0;
}
